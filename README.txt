رفيق المعلم — نسخة واجهة تطبيقية متجاوبة

الملفات:
- index.html: الموقع.
- manifest.json: بيانات تطبيق الويب.
- sw.js: عامل خدمة لتخزين الملفات الثابتة عند النشر على HTTPS.

الوظائف: لوحة تحكم، صفوف وطلاب، سجل درجات، اختبارات قصيرة بمقوّم تلقائي لسؤالين، أوسمة ونقاط ولوحة أبطال، قرص دوار، مكتبة أنشطة، شهادات، متابعة، تقارير، تصدير واستعادة JSON وCSV.

التجربة المحلية:
افتح index.html في متصفح حديث. يمكن تجربة الوظائف مباشرة. تحفظ البيانات في التخزين المحلي للمتصفح.

إضافة إلى شاشة iPhone:
1. انشر الملفات الثلاثة على استضافة HTTPS.
2. افتح رابط الموقع في Safari على الآيفون.
3. اضغط مشاركة ثم «إضافة إلى الشاشة الرئيسية».
4. افتح الأيقونة من الشاشة الرئيسية.

حدود مهمة:
هذه نسخة front-end محلية وليست خدمة سحابية متعددة المستخدمين. لا تتضمن تسجيل الدخول أو قاعدة بيانات مشتركة أو مزامنة عبر الأجهزة أو غرف مسابقات مباشرة. قبل الاستخدام المدرسي الفعلي، يلزم ربط Supabase بطريقة آمنة مع مصادقة وسياسات صلاحيات RLS، واختبار حفظ الدرجات والأوسمة والتقارير. لا تُدخل بيانات حساسة للطلاب في النسخة المحلية.
